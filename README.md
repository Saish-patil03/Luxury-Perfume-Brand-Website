# NEVORA: Luxury Perfume Brand Website

A cinematic, interactive web experience for a luxury fragrance collection. This project was generated and polished using Figma Make, featuring seamless video handoffs, responsive desktop/mobile layouts, and interactive editorial stages.

[**Live Demo**](https://meter-panic-60136147.figma.site)

## Tech Stack

* **Framework:** React + TypeScript
* **Build Tool:** Vite
* **Package Manager:** pnpm
* **Design to Code:** Figma Make AI

## Project Structure

* `src/` - Contains the core React components, TypeScript files (`photography.ts`), and global styling (`index.css`).
* `public/` - Static assets including highly optimized `.webp` and `.jpg` imagery for the editorial and product showcases.
* `.figma/` - Configuration and deployment scripts used by the Figma Make integration.
